# Global Plastic Waste & Recycling Analysis: A Country-Level Comparison

This project was developed as a final graduation project within the scope of the **Kodluyoruz Hi-Code: Data Science and AI Workshop (March/April 2025)**. 

The project aims to analyze global plastic waste production, recycling rates, per capita waste, and coastal risk levels across 165 countries. It provides data-driven insights into global sustainability trends and evaluates Turkey's standing in comparison to global averages.



##  My Role & Collaboration

This project is the result of a collaborative group effort:
* **Data Cleaning & Integration:** My team members processed the raw Kaggle dataset, handled missing values, and integrated additional socioeconomic data (`CLASS.xlsx`) to classify countries by income groups.
* **Data Analysis & Visualization (My Role):** I was responsible for the core programming and analytical phases. Using **Python inside Jupyter Notebooks**, I engineered the processed datasets, conducted correlation analyses, and selected the most effective statistical charts (Seaborn, Matplotlib, and Plotly maps) to visually communicate the project’s main goals and social impact.
